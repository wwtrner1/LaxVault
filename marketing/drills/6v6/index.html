6v6 settled (controlled scrimmage)

Game play · 20 min · 12+ players · Intermediate, Advanced

Add to my practice, freeBuild a whole practice

Setup

Full six against six in the offensive end. Start every possession from the same set (for example 2-3-1). Stop to coach, then restart. Defense clears the ball past the restraining line to win the rep.

Coaching points

  • Offense: run your set, then play off one dodge
  • Defense: one slide package, said out loud
  • Freeze it when it goes wrong, fix it, run it again
  • End with the last minutes live
